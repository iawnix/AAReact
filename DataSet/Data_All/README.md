# Data_All：原始主数据集

## 数据规模

| BATCH | 行数 | 含义 |
|---:|---:|---|
| 0 | 408 | 主数据池，用于固定的训练/内部测试划分 |
| 1 | 28 | 旧流程中的 extra 数据，不属于主训练/测试划分 |
| 合计 | 436 | 当前主数据集 |

数据文件是 `full_data_436-20260723.csv`，共有 436 个唯一 `DATA_ID`，目标列
`EE` 和 `DDG` 均有值。

## 当前主划分

以当前默认的 `seed=1`、`test_size=0.2` 为例，BATCH=0 的 408 条记录被固定划分为：

- 326 条训练数据；
- 82 条原有内部测试数据。

这 82 条测试记录是后续 Data_All4 必须保持不变的基准测试集。

## 特征和训练流程

`1_build_raw_features.sh` 根据 CSV 和 `1_sdf/` 生成 RDKit、xTB、SOAP、ACSF
原始特征。`2_build_ml_datasets.sh` 默认使用 BATCH=0 作为训练/测试池，BATCH=1
作为 extra 数据。

Data_All4 加入新数据时，不能重新随机划分这 408 条 BATCH=0 记录，否则原有测试集成员会改变。
